# Исследование моделей удаления фона (rembg)

**Дата:** 18 августа 2026 г.

## 1. Задача
Выбрать оптимальную локальную модель для веб-сервиса автоматического удаления фона (CPU-only, библиотека `rembg`).  
**Кандидаты:** `u2net`, `u2netp`, `silueta`, `isnet-general-use`.  
**Критерии:** качество сохранения объекта, скорость инференса, потребление ресурсов, стабильность на CPU, простота интеграции и лицензионная чистота.

## 2. Тестовый набор
5 изображений из `benchmark/images`, покрывающих ключевые сценарии: предметная съемка, сложные фоны, портреты (в полный рост и крупные планы), сложное освещение.  
*Ограничение:* Ground-truth маски отсутствуют. Оценка качества проводится визуально и через косвенные метрики (`foreground_ratio`, `soft_alpha_ratio`).

## 3. Обзор моделей
| Модель | Тип | Основной приоритет |
| :--- | :--- | :--- |
| `u2net` | Полноразмерная U²-Net | Баланс качества и универсальности |
| `u2netp` | Облегченная U²-Net | Максимальная скорость, низкое потребление |
| `silueta` | Облегченная | Компромисс скорости и качества |
| `isnet-general-use` | IS-Net / DIS | Детальная сегментация (особенно портреты) |

## 4. Методика и метрики
- **Окружение:** Python 3.13.2, Windows 11, CPU (без GPU), `rembg==2.0.80`.
- **Время инференса:** среднее время обработки одного изображения.
- **`foreground_ratio`:** доля пикселей, определенных как объект. (Слишком мало = обрезка объекта, слишком много = остаток фона).
- **`soft_alpha_ratio`:** доля пикселей с промежуточной прозрачностью (критично для волос и краев объектов).

## 5. Результаты бенчмарка
| Модель | Среднее время | `foreground_ratio` | `soft_alpha_ratio` | Визуальный результат |
| :--- | :--- | :--- | :--- | :--- |
| `u2netp` | **0.250 с** | 0.3195 | 0.5024 | Очень быстро, но теряет детали на сложных сценах |
| `silueta` | **0.560 с** | 0.3710 | 0.4754 | Быстро, но уступает `u2net` в стабильности |
| `u2net` | **1.638 с** | **0.3800** | 0.4676 | **Лучший общий баланс качества и скорости** |
| `isnet-general-use`| **3.732 с** | 0.3178 | 0.5054 | Хорошие портреты, но агрессивная обрезка на предметных сценах |

## 6. Анализ и итоговый выбор
- **`u2netp`**: Лидер по скорости, но качество на сложных сценах недостаточное для основного режима. Подходит как fallback при высоких нагрузках.
- **`silueta`**: Не оправдала ожиданий: в данном тесте оказалась медленнее `u2net` при сопоставимом качестве.
- **`isnet-general-use`**: Самая медленная (в 2.3 раза медленнее `u2net`). Хороша для портретов, но непредсказуема на товарах.
- **`u2net`**: **Выбранная модель**. Дает наилучший `foreground_ratio`, стабильно работает на всех типах сцен, не требует GPU и легко интегрируется. Время ~1.64 с на CPU приемлемо для текущего этапа проекта.

**Решение:** Использовать `u2net` как единственную модель по умолчанию. Остальные модели сохраняются в коде на будущее для A/B тестов или специализированных режимов, но отдельные API-эндпоинты для них сейчас не требуются.

## 7. Ограничения исследования
1. Малый датасет (5 изображений).
2. Отсутствие ground-truth масок (невозможно рассчитать точные IoU/F1).
3. Тест только на CPU (на GPU соотношения скоростей могут измениться).
4. Отсутствие нагрузочного тестирования (concurrent requests, RPS, память под нагрузкой).

## 8. Артефакты и лицензирование
- Результаты сохранены в `benchmark/results/current/` (`summary.json`, `contact_sheet.jpg`).
- **Важно:** Лицензия библиотеки `rembg` не распространяется автоматически на веса моделей. Перед коммерческим запуском необходимо проверить условия использования конкретных весов `u2net`.

## 9. Следующие шаги
1. Расширить датасет (товары, животные, прозрачные объекты, низкий контраст) и добавить ground-truth маски для расчета объективных метрик (IoU, F1, MAE).
2. Провести нагрузочное тестирование FastAPI-сервиса для определения реального throughput.

## 11. Вывод

По результатам проведённого исследования для реализации сервиса выбрана
модель `u2net`.

Важно отметить, что данное исследование не претендует на определение
глобального SOTA в области удаления фона. Сравнение проводилось среди
бесплатных моделей, доступных через `rembg` и подходящих для локального
CPU-инференса.

В рамках заданных ограничений `u2net` показала наиболее подходящий баланс
между качеством результата, скоростью обработки и потреблением ресурсов.

Для production-версии при необходимости повышения качества следует
дополнительно рассмотреть современные модели, например BiRefNet или
BRIA RMBG, с отдельной проверкой требований к вычислительным ресурсам и
лицензированию.

## 12. Лицензирование

Текущая реализация использует модель `u2net` через библиотеку `rembg`.

Для целей тестового задания модель используется в демонстрационной
реализации. Перед коммерческим использованием необходимо отдельно
проверить лицензионные условия конкретных model weights и убедиться,
что их использование в составе коммерческого сервиса разрешено.

Лицензия библиотеки `rembg` не должна автоматически рассматриваться
как лицензия на используемые model weights.
